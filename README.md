# Task 2 – Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a sales dataset using Python and Google Colab.

The purpose of EDA is to understand the dataset, identify patterns and trends, detect anomalies, and find potential data quality issues.

## Objectives
- Understand the structure of the dataset.
- Identify variables and their data types.
- Check for missing values and duplicate records.
- Analyze sales patterns and trends.
- Detect potential outliers and anomalies.
- Study relationships between numerical variables.
- Create visualizations to understand the data.

## Dataset

The dataset contains sales information for different products and regions.

| Column | Description |
|---|---|
| Date | Date of the sales transaction |
| Product | Name of the product |
| Category | Product category |
| Quantity | Number of units sold |
| Unit_Price | Price of one unit |
| Region | Sales region |
| Total_Sales | Total sales amount |

**Dataset Size:** 30 rows × 7 columns

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- CSV

## Analysis Performed
1. Data structure and dimensions
2. Data types and column information
3. Missing-value analysis
4. Duplicate-record analysis
5. Descriptive statistics
6. Histograms
7. Box plots for potential outliers
8. Correlation analysis

## Questions Explored
- Which products have higher sales?
- Which regions generate more sales?
- Which products have higher quantities sold?
- Are there missing values?
- Are there duplicate records?
- Are there potential outliers?
- Is there a relationship between quantity and total sales?

## Total Sales Calculation

```text
Total Sales = Quantity × Unit Price
```

## Key Findings
- The dataset contains 30 sales records.
- The dataset contains 7 variables.
